Problem ownership: I define the business problem and acceptance criteria before asking AI for solutions.



Code ownership: I review and understand every AI-generated code change before accepting it.



Independent practice: I regularly solve SQL and Python exercises without AI.



Data privacy: I never share passwords, API keys, credentials or confidential company data with AI.



Verification: I test AI-generated outputs instead of assuming they are correct.



Transparency: I document where AI helped, what I changed and what I independently verified. I follow any employer or assessment rules about AI use.
